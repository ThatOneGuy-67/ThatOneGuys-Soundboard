# ThatOneGuy’s Soundboard 🎵

A lightweight, embeddable web soundboard built with plain HTML, CSS, and JavaScript.  
Designed to work smoothly on **GitHub Pages**, embeds, and personal websites.

---

## Features

- Glass‑style dark theme with blur effects  
- Full‑screen responsive layout  
- Start page overlay with an “Enter” button  
- Interactive sound buttons with press animations  
- Favorites toggle to filter sounds  
- Overlap toggle for playing multiple sounds at once  
- Stop all sounds button  
- Search bar for quickly finding sounds  
- Pure HTML/CSS/JS — no frameworks required
